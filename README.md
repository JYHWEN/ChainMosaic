# ChainMosaic

ChainMosaic: a distributed, high-performance platform for real-time data processing, leveraging auto-scaling capabilities and decentralized node clustering.

ChainMosaic is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainMosaic.git`
2. `cd ChainMosaic`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainMosaic is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
